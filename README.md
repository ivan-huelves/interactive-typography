Esta investigación explora cómo la tipografía interactiva expanden los procesos de significación en entornos digitales. A través del desarrollo de un modelo conceptual y operativo y la creación de prototipos, exploro como el tipo abandona su estatismo tradicional para transformarse en un sistema vivo capaz de interactuar en tiempo real a datos de sensores, algoritmos y acciones del usuario.

Este sitio web documenta los resultados prácticos y teóricos de la investigación. La plataforma se estructura en un cuaderno de bitácora con las últimas novedades de la investigación, una colección de prototipos experimentales de elaboración propia, una base de datos interactiva con los casos de estudio que conforman el marco de referencia, y una selección de proyectos de estudiantes que evidencian la transferencia de este conocimiento.
