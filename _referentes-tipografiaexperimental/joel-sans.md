### Descripción
Esta propuesta plantea una tipografía interactiva capaz de reaccionar a diversos aspectos musicales en función del género. La fuente se articula sobre cuatro ejes de variación (peso, ancho de carácter, contraste y ángulo) que modifican su morfología en respuesta a parámetros como el ritmo o el volumen. El proyecto nace con el objetivo de democratizar el diseño gráfico para músicos emergentes y constituye el germen de una herramienta web generativa que permite crear cartelería y contenido para redes sociales derivado directamente de las pistas de audio. A nivel técnico, la investigación resultó clave para resolver el reto de la detección del tempo, integrando la librería Web Audio API de Mozilla.

Este conjunto de propuestas evidencia la flexibilidad del modelo para gestionar distintas configuraciones de relación. En el caso de #3EFF3F se articula una relación divergente donde convergen valores de entrada sonoros y gestuales para modificar simultáneamente múltiples ejes, mientras que Joel Sans y Grix establecen relaciones directas centradas exclusivamente en el audio. En todos los casos, el sistema emplea una función normalizadora instrumentada por librerías de procesamiento (como Web Audio API, Minim o PoseNet) encargadas de cuantificar magnitudes físicas para adaptarlas al espacio de diseño de la fuente. A partir de estos datos, la función significativa opera bajo lógicas de reactividad, vinculando la intensidad del estímulo con la modificación de diversos ejes de variación (peso, expansión, contorno). Esta arquitectura confirma el requisito de expandir los procesos de significación, transformando la tipografía estática en una entidad performativa capaz de hacer tangible el ritmo y las dinámicas sonoras de la composición musical.
