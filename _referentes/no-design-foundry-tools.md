### Relevancia
Este proyecto genera una colección de herramientas web (X-Ray, Pan, Rastr, Rotorizer) que procesa archivos de fuentes subidos por el usuario aplicando filtros para alterar su morfología original.

Su aportación consiste en proponer un sistema generativo de fuentes experimentales. Al permitir la customización mediante parámetros, el proyecto habilita a usuarios no especializados para intervenir en la forma del glifo y generar versiones inéditas a partir de diseños previos.

La relevancia para la investigación radica en que, a diferencia de otros referentes limitados a *outputs* de imágenes *bitmap* o vídeos, este sistema devuelve un archivo fuente funcional (.otf/.ttf). Esto valida el uso del código no solo para la exploración visual, sino como herramienta capaz de generar *software* tipográfico disponible en otros entornos de diseño.
